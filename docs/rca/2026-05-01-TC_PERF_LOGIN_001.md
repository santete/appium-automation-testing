## Root cause

Performance threshold (login P95 < 2000ms) trong Assertion Contract được hard-code theo real device baseline (spec §7.5), nhưng spec đang được chạy trên emulator có hardware profile khác — emulator P95 baseline thực tế ~4-5x chậm hơn. Đây là **threshold mismatch**, không phải product perf regression.

### Technical detail

- `tests/perf/login-perf.spec.ts:23` literal: `const SLA_MS = Number(process.env.PERF_LOGIN_SLA_MS ?? 2000);` — env override **đã có** nhưng không được set trong run này.
- Emulator P95 measure 3 run = [4462, 4318, 4501] → mean ~4427ms, std ~92ms (consistent, not noise).
- Real device baseline (theo spec §7.5 footnote): Pixel 6 USB-tethered ADB perf p95 ≈ 1450-1650ms với cold start.
- Emulator overhead breakdown (Appium log):
  - UiAutomator2 server bootstrap: +800ms vs real device
  - WebView render frame: +1.5-2s vs real device (no GPU passthrough)
  - ADB shell roundtrip: +200-300ms per command
- Threshold không phải sai — chỉ là không-aware-env. Cần env-aware override không phải tighten threshold.
